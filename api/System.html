System

System(
    label=None,
    num_states=1,
    energies=None,
    decays=None,
    initial_state=None,
    fields=None,
    b_field=None,
)

An open quantum system: its states, decays and the fields coupling them.

The system can be an atom or any other few-level quantum system, such as a quantum dot or a colour centre.

Parameters

Name Type Description Default
label str | None string label describing the system. None
num_states int number of states. 1
energies list[float] | None absolute or relative energy levels of the states. None
decays list[dict] | None list of dicts representing decays. e.g. [ { “rate”: 1.0, “channels”: [[0,1]], “factors”: [1.0] } { “rate”: 2.0, “channels”: [[2,1], [3,1]], “factors”: [0.707, 0.707] } ] None
initial_state list[float] | None initial state, as a list or array None
fields list[dict] | None list of dicts representing the fields that couple the system’s states. None
b_field dict | None a DC magnetic field along the quantisation axis, as a dict with the keys magnitude (default 0), units ("natural", the default, or "gauss"), and the per-level lists g_F and m_F (length num_states). It adds g_F * m_F * B to the level energies (H_0 += 2 pi g_F m_F B), with the sign convention of Steck’s alkali data (see clerq.hyperfine). "natural" means mu_B * B / h in the same frequency unit as energies; "gauss" assumes energies in MHz (time in microseconds). For hyperfine systems, Atom1e.get_zeeman_levels() gives g_F and m_F. None

Attributes

Name Description
b_field The validated b_field dict (a copy: assign a new dict to change it).
b_field_natural The B-field magnitude in natural units (mu_B B / h); 0 if none.
zeeman_coeffs g_F * m_F of each level: the Zeeman shift per unit natural B.

build_initial_state

System.build_initial_state(initial_state=None)

Build the initial density matrix for the system.

The default is for all of the population to be in |0><0|.

Parameters

Name Type Description Default
initial_state list[float] | None a list or array of populations, length num_states. If not given, all the population starts in level 0. None

Returns

Name Type Description
qu.Qobj The initial density matrix, diagonal with the given populations.
qu.Qobj It is also stored as self.initial_state and self.rho.

Raises

Name Type Description
ValueError If initial_state has the wrong length or its elements do not sum to 1.

Notes

  • The elements must sum to 1 (as this will be the trace of the density matrix).

get_fields_sum_coherence

System.get_fields_sum_coherence(states_t=None)

Returns the sum coherences of the system density matrix for each field, including the relative strength factors.

Notes

The coherence of each coupled pair is weighted by the pair’s (signed) factor, i.e. by its dipole matrix element, the same factor that multiplies the pair in the interaction Hamiltonian. The field’s polarisation is then sum_k factor_k * rho_{a_k b_k}, and in the weak-probe limit the response goes as the line strength sum_k factor_k**2.

Parameters

Name Type Description Default
states_t np.ndarray | None (optional) a states_t object. If not provided, use self.states_t() None

Returns

Name Type Description
np.ndarray np.ndarray of shape (num_fields, t_steps+1)

set_H_Omega

System.set_H_Omega(rabi_freqs, rabi_freq_t_funcs, rabi_freq_t_args)

Set the Rabi frequency part of the interaction Hamiltonian.

Updates each field’s Rabi frequency and time function, then rebuilds the Hamiltonian.

Parameters

Name Type Description Default
rabi_freqs list[float] Rabi frequency for each field. required
rabi_freq_t_funcs list Name of the time function for each field, as in clerq.t_funcs (e.g. "gaussian"). required
rabi_freq_t_args list[dict] Argument dict for each field’s time function. required

Returns

Name Type Description
list The list of Rabi frequency Hamiltonian terms, one for each field.
