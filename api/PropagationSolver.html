PropagationSolver

PropagationSolver(
    system=None,
    t_min=0.0,
    t_max=1.0,
    t_steps=100,
    method='mesolve',
    opts=None,
    savefile=None,
    z_min=0.0,
    z_max=1.0,
    z_steps=10,
    z_steps_inner=2,
    num_density_z_func=None,
    num_density_z_args=None,
    interaction_strengths=None,
    velocity_classes=None,
    *,
    atom=None,
)

Solver for the propagation of fields through a medium of systems.

Steps the fields through space with a finite-difference method, solving the Lindblad master equation for the :class:~clerq.system.System at each step (once per velocity class if the medium is Doppler broadened).

Parameters

Name Type Description Default
system dict | None Dict (or empty dict for defaults) describing the quantum system; passed to :class:~clerq.system.System. None
t_min float Start time of the simulation. 0.0
t_max float End time of the simulation. 1.0
t_steps int Number of time steps. 100
method str Solver method — 'mesolve' (Lindblad master equation) is the only supported value. 'mesolve'
opts dict | None Dict of QuTiP solver options. None
savefile str | None Path prefix for caching solved results ('.qu' extension appended automatically). Pass None to disable caching. None
z_min float The front of the medium. 0.0
z_max float The back of the medium. 1.0
z_steps int Number of space steps at which the solution is recorded. 10
z_steps_inner int Number of finite-difference steps made within each space step. 2
num_density_z_func str | None Name of a function in clerq.t_funcs giving the number density profile over z. Square by default. None
num_density_z_args dict | None Dict of arguments for num_density_z_func. None
interaction_strengths list[float] | None Interaction strength of each field with the medium, one for each field. None
velocity_classes dict | None Dict defining the velocity classes for Doppler broadening, or None for no broadening. thermal_width and the thermal_delta_* values are cyclic frequencies, in the same units as decays rates and rabi_freq. The weights are Gaussian, exp(-(delta / thermal_width)**2). None
atom dict | None Deprecated name for system. None

build_zlist

PropagationSolver.build_zlist(z_min, z_max, z_steps, z_steps_inner)

Builds the space grid.

Parameters

Name Type Description Default
z_min float The front of the medium, in your chosen length unit. required
z_max float The back of the medium. required
z_steps int The number of even-spaced steps on which to solve and record the solution. required
z_steps_inner int Between each z_step, make this many inner steps of the finite-difference solver (for numerical stability). required

Notes

  • If the problem requires a lot of space steps for stability, but you don’t need to record the solution at such a high-level of resolution, increase z_steps_inner.

PropagationSolver.coherences(coupled_levels)

Gets the sum of coherences (off-diagonals) in a list of coupled level pairs.

Parameters

Name Type Description Default
coupled_levels list[list[int]] a list of pairs of level indexes required

Returns

Name Type Description
np.ndarray np.array, shape (z_steps+1, t_steps+1), dtype=complex

Note

Unlike System.get_fields_sum_coherence, which operates on a single-z time series with per-field weighting factors, this method sums over the full (z, t) array with unit weights.

load_results

PropagationSolver.load_results()

Loads the solution from a QuTiP pickle file.

Raises

Name Type Description
ValueError if the savefile was built from a different problem definition (hash mismatch), or was solved with the old factor**2 source-term weights and a field has factors other than 1.

Notes

  • The path from which the results will be loaded is taken from self.savefile.
  • Old savefiles without metadata are loaded without integrity checking, with a warning, unless a field has factors other than 1 (see Raises).

solve

PropagationSolver.solve(
    step='ab',
    rho0=None,
    recalc=True,
    progress=True,
    progress_show_area=False,
    check_counter_prop_depletion=True,
    depletion_warn=0.01,
    depletion_error=0.1,
)

Solves the propagation of the fields through the medium.

Parameters

Name Type Description Default
step str ‘euler (for Euler method) or ’ab’ (for Adams-Bashforth) 'ab'
rho0 Qobj the initial density matrix state None
recalc bool Recalculate the solution even if a savefile exists? True
progress bool Show a tqdm progress bar with elapsed time, ETA and current max field amplitude. True
progress_show_area bool Extend the progress bar with the pulse area ∫|Ω|dt for each field at the current z-step. Requires progress=True. False
check_counter_prop_depletion bool Run a post-solve depletion check on any counter-propagating fields. Set False to suppress. True
depletion_warn float Depletion fraction that triggers a UserWarning. 0.01
depletion_error float Depletion fraction that raises CounterPropagatingDepletionError. 0.1

Returns

Name Type Description
np.ndarray self.Omegas_zt: The solved field complex Rabi frequency at each point in space z and time t.
np.ndarray self.states_zt: The solved density matrix at each point in space z and time t.
